# Assignment 04: Interactive Weather Dashboard using Charts & Live API

## Objective
To build an interactive weather analytics dashboard that queries current weather conditions and hourly forecasts for any city, displaying real-time metrics with graphical charts.

## Technologies Used
- HTML5 & CSS3
- JavaScript (Fetch API, Async/Await)
- Chart.js (Data Visualization)
- Open-Meteo / Weather API

## Features Implemented
- City search with real-time temperature, wind speed, humidity, and condition lookup.
- 24-hour temperature trend visualized using an interactive Chart.js line graph.
- Dynamic theme adjustment based on day/night conditions.

## Directory Structure
```
Assignment 04 - Interactive Weather Dashboard/
├── index.html        # Dashboard layout and chart containers
├── style.css         # Dashboard styling and widgets
├── script.js         # API integration and Chart.js rendering
└── README.md         # Assignment documentation
```

## How to Run
Open `index.html` in a web browser.
