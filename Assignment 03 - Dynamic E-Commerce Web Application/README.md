# Assignment 03: Dynamic E-Commerce Web Application (NeoCart)

## Objective
To develop an interactive client-side e-commerce web application with dynamic product catalogs, real-time search, price filtering, category filtering, and shopping cart state management using vanilla JavaScript.

## Technologies Used
- HTML5
- CSS3 (Modern Glassmorphism & Cards)
- JavaScript (DOM Manipulation, Array methods, LocalStorage)

## Features Implemented
- Dynamic product rendering from JavaScript data objects.
- Real-time search filter and price-range sorting.
- Add-to-cart, quantity counter, item deletion, and live total calculation.
- Responsive design tailored for mobile and desktop screens.

## Directory Structure
```
Assignment 03 - Dynamic E-Commerce Web Application/
├── index.html        # Main e-commerce shop page
├── style.css         # Styling and layout
├── script.js         # Search, filter, cart logic
├── assets/           # Product images and banner
└── README.md         # Assignment documentation
```

## How to Run
Open `index.html` in a web browser.
