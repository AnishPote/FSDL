# Assignment 06: E-Commerce Platform for Selling Used Items (Node.js & MongoDB)

## Objective
To develop a full-stack peer-to-peer marketplace application where users can list pre-owned goods for sale, browse localized categorized listings, and connect with sellers using Node.js, Express.js, and MongoDB.

## Technologies Used
- Node.js & Express.js
- MongoDB & Mongoose
- HTML5, CSS3 (Poppins & Flexbox layout)

## Features Implemented
- Product listing creation with title, price, category, condition, location, and seller contact.
- Database query endpoints with sorting and categorization.
- Responsive marketplace grid with card hover interactions.

## Directory Structure
```
Assignment 06 - Used Items E-Commerce Platform/
├── server.js               # Express application entry
├── models/
│   └── Product.js          # Mongoose product listing schema
├── public/
│   └── index.html          # Marketplace frontend
└── README.md               # Assignment documentation
```

## How to Run
```bash
npm install express mongoose
node server.js
```
Access `http://localhost:3000`.
