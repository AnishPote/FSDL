# Assignment 02: Responsive HTML & CSS Web Layout Design

## Objective
To design and develop a responsive personal portfolio web page showcasing professional bio, skills, project cards, and social links using modern CSS3 flexbox and grid layouts.

## Technologies Used
- HTML5 Semantic Elements
- CSS3 (Flexbox, Media Queries, Boxicons)

## Features Implemented
- Dark theme styling with responsive typography.
- Mobile-first adaptive design supporting desktop, tablet, and mobile breakpoints.
- Interactive navigation bar with hover effects.
- Project cards and skills showcase sections.

## Directory Structure
```
Assignment 02 - Responsive Web Layout/
├── index.html        # Portfolio layout HTML structure
├── style.css         # Styling, responsive grid & media queries
└── README.md         # Assignment documentation
```

## How to Run
Open `index.html` in any web browser.
