# Assignment 01: HTML Text Formatting Tags & Basic Page Structure

## Objective
To understand and implement basic HTML document structure, heading tags, paragraph formatting, tables, lists, and specialized text formatting tags (`<b>`, `<i>`, `<u>`, `<mark>`, `<sub>`, `<sup>`, `<code>`, `<pre>`).

## Technologies Used
- HTML5
- CSS3 (Internal styling & layout)

## Features Implemented
- Comprehensive tabular overview of HTML formatting tags with code snippets and visual examples.
- Semantic HTML tags hierarchy (`<header>`, `<table>`, `<tr>`, `<th>`, `<td>`).
- Modern responsive layout styled with clean typography and hover transitions.

## Directory Structure
```
Assignment 01 - HTML Text Formatting Tags/
├── index.html        # Main HTML file with formatting tags implementation
└── README.md         # Assignment documentation
```

## How to Run
1. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox).
